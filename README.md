# ✅ Lista de Tarefas

Uma aplicação de lista de tarefas desenvolvida em **Python** utilizando **Tkinter**.

O projeto possui uma interface gráfica minimalista para adicionar, concluir e excluir tarefas.

## 📸 Sobre o projeto

A aplicação foi desenvolvida como parte dos meus estudos em Python e desenvolvimento de interfaces gráficas.

## ✨ Funcionalidades

- Adicionar tarefas
- Concluir tarefas
- Excluir tarefas
- Limpar todas as tarefas
- Contador de tarefas
- Contador de tarefas concluídas
- Suporte à tecla Enter para adicionar tarefas
- Barra de rolagem
- Interface gráfica minimalista

## 🛠️ Tecnologias utilizadas

- **Python**
- **Tkinter**

## ▶️ Como executar

### 1. Clone o repositório

```bash
git clone https://github.com/SEU-USUARIO/lista-de-tarefas-tkinter.git
```

### 2. Entre na pasta do projeto

```bash
cd lista-de-tarefas-tkinter
```

### 3. Execute o programa

```bash
python lista_tarefas.py
```

> O Tkinter normalmente já acompanha a instalação do Python, portanto não é necessário instalar bibliotecas externas para executar o projeto.
